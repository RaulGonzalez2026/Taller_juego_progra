# VIDEO JUEGO

# 1 fase del proyecto (ANALISIS)
hablando de esta fase del proyecto, en este lo que realice fue una construcción de mi proyecto realizando primeramente un análisis de lo que quería formar como videojuego viendo que si y que no podía colocar
para mi futuro juego realizando mi idea y mi boceto de lo que quería, en este caso, el videojuego de ahorcado

# 2 fase del proyecto (DIAGRAMA DE FLUJO)
En esta fase del proyecto nos enfocamos mas en el proyecto mismo, realizando los últimos pasos para irnos directamente a programar, haciendo el paso a paso de nuestro juego, donde le damos una dirección a nuestro juego,
para que cada cosa tenga sentido y dirección

# 3 Fase del proyecto ( CODIGO )
Finalmente despuesd de planearlo todo y pensarlo de manera buena, haciendo le paso a paso y como queremos ejecutar el juego, empezamos a programarlo, debido a que no soy tan bueno en la programacion,
para ayudarnos vamos a utilizar la IA utilizandola de manera estrategica, despues de esto y haciendo correciones logramos realiar el codigo de nuestro programa, para hacerlo un videojuego divertido y ejecutable

# 4 Fase del proyecto (PRESENTACION FINAL)
Luego de realizar todos los debidos pasos, a continuacion subimos los documentos a github para que nuestro profesor pueda visualizarlo y opinar de nuestro esfuerzo, donde a pesar que podamos cometer errores,
esperamos que haya realizado mi programa de buena manera
